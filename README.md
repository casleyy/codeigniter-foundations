# CodeIgniter POS Foundations

A basic four-page POS website created using CodeIgniter 4.

## Pages

- Home
- About
- Customer Accounts
- User Accounts

Customer and user records are stored in static PHP arrays. No database is used in this activity.

## How to Run

1. Install XAMPP.
2. Place the project inside `C:\xampp\htdocs`.
3. Start Apache.
4. Open `http://localhost/codeigniter-foundations/`.
